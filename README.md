# Homebrew tap for speckeep

[Homebrew](https://brew.sh) tap for [`speckeep`](https://github.com/bzdvdn/speckeep) — strict, lightweight spec-driven development for coding agents.

```bash
brew tap bzdvdn/speckeep
brew install bzdvdn/speckeep/speckeep
# or in one line:
brew install bzdvdn/speckeep/speckeep
```

The formula builds from source (requires Go) and installs the single `speckeep` binary.

Docs: <https://bzdvdn.github.io/speckeep/> · MIT
